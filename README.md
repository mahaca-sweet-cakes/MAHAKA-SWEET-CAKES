# MAHACA Sweet Cakes - website

BUC3106 E-Commerce Capstone Project, MUBS Jinja Campus.

## Files

| File | What it is |
|---|---|
| `index.html` | Home page: heading, one sentence about the business, three reasons to choose us, featured cakes, how to order |
| `products.html` | All eight cakes and prices, in three collections |
| `about.html` | The story behind the name MAHACA, values and founders |
| `pay.html` | How to Pay and Order: four payment methods, payment confirmation, refund rule |
| `policies.html` | Delivery, returns, privacy notice, terms, honest claims |
| `style.css` | All the design for every page (colours, fonts, layout) |
| `images/` | Logo and photos. The current images are placeholders - replace them. |
